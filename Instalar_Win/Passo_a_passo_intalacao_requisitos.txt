Como instalar (Windows)
========================

Antes de tudo: baixar o programa
---------------------------------
1. No site do GitHub do programa, clique no botão verde "Code" e depois
   em "Download ZIP".
2. Abra a pasta Downloads, clique com o botão direito no arquivo .zip
   que foi baixado e escolha "Extrair tudo..." e depois "Extrair".
   IMPORTANTE: não rode o programa de dentro do .zip, ele não funciona
   assim. Use sempre a pasta que foi extraída.
3. Se quiser, mova a pasta extraída para Documentos.

Instalar
---------
1. Verifique se o computador está conectado à internet.
2. Dentro da pasta do programa, abra a pasta "Instalar_Win" e dê dois
   cliques no arquivo "instalacao.bat".
   Se o Windows mostrar "O Windows protegeu o computador", clique em
   "Mais informações" e depois em "Executar assim mesmo".
3. Aguarde. A janela preta vai mostrar o andamento sozinha — não é
   preciso clicar em nada, só esperar até aparecer a mensagem:
   "Instalacao concluida com sucesso!"
4. Aperte qualquer tecla: o programa abre sozinho.

Pronto! Das próximas vezes, é só dar dois cliques no ícone
"Bateria de Funções Executivas" que foi criado na área de trabalho.
(Se o ícone não aparecer, dê dois cliques em "INICIAR_BATERIA.bat",
na pasta do programa.)


Se der algum erro
------------------
- Confira a internet e rode "instalacao.bat" de novo (pode rodar quantas
  vezes quiser, ele pula o que já está instalado).
- Se a tela de instalação do Python aparecer pedindo para marcar uma
  caixinha, marque "Add python.exe to PATH" antes de clicar em "Install Now".
- Se nada disso resolver, tire um print da mensagem de erro e envie
  para o suporte (edf.tercio@gmail.com).


O que esse arquivo instala
----------------------------
- Python 3.11 (se ainda não estiver instalado no computador)
- As bibliotecas Python usadas pelas tarefas: numpy, pygame, pandas e
  openpyxl (usada para salvar a planilha de resultados)
- O ícone "Bateria de Funções Executivas" na área de trabalho e no menu
  Iniciar
